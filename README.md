An independent GTA VI trophy field guide and browser tracker for [the make.fun bounty](https://make.fun/bounty/gta6-trophy-guide-01). All 55 kit-listed PS5 trophies, exact official names, descriptions and grades; original cited guidance; a sequenced platinum roadmap; an explicitly qualified missable warning. No Rockstar assets, dependencies, telemetry or remote runtime requests.

## Open it

Run `node serve.ts`, then visit `http://127.0.0.1:8080`. Node 22.18+ is sufficient. Serve `app/` as the root with any static server; no build step or package install. Offline means network access beyond that local static server is unnecessary. Source links open only on an explicit click.

## Use it

Select any trophy to open its guide. Filter by kind, grade and earned status, or search. Story spoilers are hidden until earned by default; enabling spoilers reveals them. Checkboxes, counters, notes, bookmarks and roadmap tasks persist in this browser. Export a JSON backup and import it in another browser. Imports are validated completely before replacing progress. Demo progress is an explicit opt-in and clearly labelled.

## Research and limits

Research rechecked November 20, 2026: all 17 PowerPyx pages were reachable; Exophase returned HTTP 403, so its existing kit metadata is retained and its access restriction is visible. Every trophy now has 2–4 numbered steps, each with its own source numbers, plus the original prose fallback. The tracker keeps all 18 source pages in a coverage rail. The audit computes guide coverage, cited steps, single-source guides and four documented source differences. The 28-hidden figure remains the kit's PSN-list total, not an inference about individual trophies.

The four differences are qualified: 18 meditations versus the 100% target of 15; inconsistent final-mission chapter labels; eight required stranger strands versus four named examples in an incomplete guide; and eight large vaults within 22 total bank jobs. These are not four proven contradictory unlock methods. The Chapter 1 meditation remains a precaution. The recheck found newly reported methods for In The Beginning… and Ten Pin; Bad Luck, I Guess is still unknown, and Fair Game's exact animal remains unconfirmed. Research Hold retains all three rechecked cards with their current status. No guide claims personal gameplay verification.

## Deliverable

`MAKEFUN_OUTPUT_DIR=out node main.ts` copies `app/` and four real browser captures into `out/`, then calls the unmodified kit dossier library. The entrypoint is standard-library-only and deterministic. `shots.json` records the capture views; `scripts/verify.mjs` checks the app in Chromium and captures them. Screenshots show labelled demo progress, never a fabricated personal save.

The optional verification script uses an existing Playwright installation. Set `PLAYWRIGHT_MODULE` to its local module URL and `CHROME_PATH` to cached Chromium; no install is needed. It reads the viewports and paths in `shots.json`, tests every trophy's numbered steps, all four source differences and all 18 coverage counts, then captures with Chromium's `--screenshot` command. Verification also covers backup round trips, rejected imports, persistent counters and notes, story concealment, filtering, mobile overflow, all 55 roadmap chips, chapter watches and external-request blocking. Screenshot 2 captures a real validated import of the downloaded demo backup and its earned/counter toast. Save & sources also records actual export receipts. Stage hours are overlapping source estimates, not additive budgets. Recording validation remains the server's check against sealed recordings; local checks take no transcript upload for this competition.
